# DAQ K-4 本机 Dev 合成知识消费演练

**日期：** 2026-10-09。只使用 pytest 临时目录中的合成 `entity/claim/link` 记录和合成来源；无真实数采事实进入发布。活动指针、快照和状态文件都在测试临时目录，未写入项目 `data/knowledge/published`。

演练了发布后显式激活、进程内固定版本、切换后新进程读取新版本及既有版本回滚；活动清单哈希、记录事实/权限指纹和来源哈希在加载时复核，链接根目录与不合法记录拒绝。`internal_fae` 能取到其可见规格及结构化来源；`channel` 对无权记录得到缺证且不暴露标题/路径。链接即使可查看，缺转发许可也不能从 `official_links` 或普通检索取得；获转发许可后仍只由 `official_links` 交付。

同一实体、字段在不同适用范围有不同已核验值而查询未指定范围时，规格工具返回需要补条件，不任选一个值。实际匹配的结果才回填需求 ID；无结果的正确查询记录缺证，错误设备查询不替其他需求宣布缺证。认证入口在有活动快照但尚无细粒度角色合同时拒绝启动。本机 Dev 健康信息报告活动快照哈希；没有活动指针时仍为 `empty-dev-v0`。

独立代码复审复现了软件记录 URL 绕过链接核验、流程错配实体、软件适用条件漏检和纯实体错误覆盖平台需求。修复后，非链接记录出现带协议、无协议或域名路径形式的地址会拒绝加载；流程必须经可见拓扑匹配设备；软件支持工具要求完整的硬件修订、连接、平台、版本和功能组合。用户明确说出的连接方式会进入需求条件。仅给出 Windows/Viewer 2.0、未给硬件修订、连接方式或目标功能时，即使存在 rev-A USB 录制记录，也不标为完整兼容证据。纯实体记录不证明 Linux 等平台可用。
