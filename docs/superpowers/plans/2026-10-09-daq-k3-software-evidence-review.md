# DAQ K-3 软件证据复审实施计划

**目标：** 将真实软件与固件资产纳入只读候选复审和增量差异流程，保持资产存在与兼容结论之间的证据边界。

**架构：** 在已有 K-2 复审包增加受限 `asset_path` 选择器；K-3 配方只给出复审问题与匹配规则。私有包沿用归档重校验、`0600` 和 Git 忽略输出。

**技术：** Python 3.11、标准库、pytest。

## 约束

- 原件与用户附件不自动成为权威知识；二进制只留元数据。
- 包名不是下载 URL；功能变更记录不是设备端到端测试。
- 事实、链接和查看/转发权限均须具名复审；本批不发布可答知识。
- 不修改相机运行时或知识。
