# 数采 FAE 知识目录

`drafts/` 是 Git 忽略的私有候选工作区。每个不可覆盖的目录按相机 FAE 的分层结构组织产品正文、结构化事实、专题、选型、软件/SDK、链接和原件索引；数采组合系统另有 `systems/`。原始二进制保留在受限归档，不直接复制进知识正文。

候选内容由 `scripts/materialize_candidate_knowledge.py` 从已核对的原件归档及 A1～C4 私有产物重建，含输入/输出哈希清单。目录本身不被运行时加载，也不代表事实、权限或链接已签认。审核后须经独立的知识编译、静态审计、Dev 发布与回放门；每次资料更新生成新的候选目录，保留旧目录和影响图供复审。
