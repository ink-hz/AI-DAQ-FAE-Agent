# DAQ K-4 本机 Dev 知识消费设计

K-1 可生成不可变本机发布与原子活动指针，但当前 API 固定使用 `empty-dev-v0`。本批只让本机 Dev 加载经 K-1 发布的活动快照，先在工具检索前按角色过滤；认证与 Platform Task 没有已审核的细粒度角色映射，存在真实活动快照时须拒绝启动，不能把入口白名单等同于资料授权。

启动时读取活动指针、校验内容地址和记录审核指纹、来源哈希、可答状态；文件损坏或不符合合同则启动失败。活动版本在进程内冻结，切换后重启才生效，健康和 trace 显示确切知识版本。空指针保持现有空知识行为。只把 `verified/unsupported` 且本角色可查看的记录送入工具；链接交付另需本角色可转发。`candidate/conflict/unknown` 均不可冒充已核验事实，冲突可留在后台审计，不放入普通检索结果。

工具结果返回状态、适用条件、记录内容和结构化来源。只有实际匹配本轮需求的已核验来源才回填 `matched_requirement_ids`。查询不匹配或权限不足时保持可见缺证，不泄漏被过滤记录数量、标题或路径。所有可交付地址只能存在于经过链接复审且允许转发的 `link` 记录，普通检索不返回链接；软件/SDK/规格记录携带带协议、无协议或域名路径形式的地址时，整个活动快照拒绝加载。流程必须关联本角色可见的拓扑并匹配请求实体；软件支持按设备、硬件修订、平台、连接方式、软件版本和功能精确匹配。未给出修订、连接方式或目标功能的广义兼容问题不能由单一条件记录标记为完整覆盖。纯实体记录不能证明平台可用性。用户附件和会话断言仍不能成为产品事实。真实模型回放只在 Dev；本批用合成已审核快照测试权限、来源、发布版本与回滚。

此消费者不等于真实资料已裁决，也不启用生产或未完成角色合同的认证入口。后续仍须完成持久归档、具名审核、真实 K-4 静态审计、Dev 独立答案复审与试点门。
