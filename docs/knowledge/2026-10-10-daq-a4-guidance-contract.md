# A4 选型、排障、风险与经验候选合同

本批属于 capability evidence 候选制备，不接入运行时工具、在线视图或知识发布。复用 A2/A3 的稳定 section_id、原件引用、正文 SHA-256、依赖关系、候选状态、空事实/权限审核和空查看/转发角色。

每节按 selection、troubleshoot、risk、experience 标记能力。每个正向条目有独立 item_id、准确实体集合、所属 topology_id、适用条件、精确 source_refs、正文和证据层。文档要求、建议、参考配置及不适用条件保留原分类。故障触发条件、检查顺序与正常操作区分；没有原因证据时不诊断，没有恢复分支时不补写操作。

证据层分别为 product_specification、documented_procedure、combination_validation 和 field_experience。产品规格不能作为组合结论或操作依据；文档步骤不能自动提升为实测或经验。后两类须有独立证据记录及匹配条件和来源，但结构校验并不证明记录真实性。本批两类均为空。产品参数继续作为 A2 依赖，避免重复生成参数表。

缺口目录包含 gap_id、能力、实体、拓扑、适用条件、限定审计范围、来源定位、依赖章节、缺失内容及所需补证。audited_missing 只表示所列范围没有闭合证据，不代表设备不支持或全库没有资料。每节显式引用 gap_ids；后续消费者可按能力与范围定位缺口，只有经事实及权限审核后才可进入发布视图。

`validate_guidance_section` 调用既有候选章节校验，再验证条目条件、来源闭合、实体/拓扑一致和证据层边界。私有校验另外重读原件、重算文件/正文/输入指纹，验证缺口闭合与依赖、条件分支、文件权限和 Git 忽略规则。二者都不授予发布资格，也不替代具名事实和权限复审。
