# DAQ K-3 软件、固件与交付证据复审指引

K-3 私有包把原归档中的软件与固件文件、变更记录和原包索引定位到稳定议题。它只提供待审线索；文件存在、文件名中的版本号和变更记录均不证明设备兼容、功能实测或交付许可。二进制只返回相对路径、文件 SHA-256、大小和文件级定位，不解包、不索引内容、不生成下载地址。

## 复审和记录

1. 产品/研发为每个软件和固件包确认实际版本、平台/架构、适用 SKU 与硬件修订、连接方式、依赖版本和测试条件。Viewer 的配对、录制、升级，固件的同步与回退，分别要求实测记录；仅有变更日志时保留候选状态。
2. 对升级工具、烧录工具和操作文档，研发另行确认适用设备、标定保护、失败及回退条件。不得从包名或原包说明自动生成用户操作步骤。
3. 资料所有者按每份原件和每条派生记录分别签认 `internal_fae`、`tmall_support`、`channel` 的查看与转发范围。原件自称的 `public/confidential/unknown` 不是授权。可查看也不意味着可转发。
4. 外部页面须记录最终 URL、页面标题、页面版本/抓取时间、相关产品的确切 SKU 映射、链接有效性及各角色权限。原包 `README.txt` 中的地址是待核验线索，不作为下载入口。官网产品页和下载页也须分别核验。
5. EG-DB 与 Gemini 335L 的包含关系先由产品/研发裁决；相机知识维护者再提供固定版本的只读模块事实投影。模块标称参数不能直接变成 EG-DB 整机能力。
6. 签认后转换成 K-1 `software` 或 `link` 记录，保留精确 `source_ref`、事实复审与权限复审指纹；链接还需独立链接复审指纹。来源、条件或范围发生变化时重新审核，发布新不可变版本并保留回滚点。

## 本批待决问题

| 议题 | 需要具名裁决的内容 |
| --- | --- |
| SDK/Viewer/BLE/Android 包 | 各包真实版本、平台及与 EGO、EGO Pro、EG-DB、WristCam 的逐组合兼容测试 |
| Viewer 变更记录 | 配对组、录制、固件升级对设备修订、固件和连接方式的实际适用范围 |
| EGO/EGO Pro 固件 | 适用 SKU、升级/回退路径、同步拓扑及标定保护 |
| 工具与资料 | 升级工具、烧录工具、说明文档和视频的操作许可、交付对象及安全边界 |
| 原包与官网链接 | 页面逐页核验、最终 URL、是否可向各角色查看或转发 |
| EG-DB 模块 | Gemini 335L 的确切模块修订、只读投影来源版本、模块与整机性能边界 |

## 快速更新

每次资料更新先封存新原件并生成新哈希清单，再导入新候选快照、生成 K-2/K-3 复审包和差异报告。只重审变化来源影响的议题及新增未映射来源；旧在线发布保持可回滚。即使文件名相同，字节哈希改变也需要重新核对来源与审核指纹。增量流程不能跳过资料所有者、产品/研发或独立答案复审。

本指引没有授予任何资料或软件的查看、转发或下载权。在线服务当前仍使用 `empty-dev-v0`。
